     Collaptris

      Неоновый тетрис с механикой распада блоков.

           Геймплей
- Классический тетрис с уникальной механикой
- Блоки распадаются при заполнении линии
- Неоновый визуальный стиль
- Система рекордов

             Технологии
- Unity, C#
- UI Canvas
- Android (Google Play)
